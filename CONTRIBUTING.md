# Como contribuir

- **Bugs** — procure relatos semelhantes nas issues. Se precisar abrir um novo,
  use o modelo de bug e inclua a plataforma, as versões, os passos, o resultado
  esperado e os logs relevantes. Remova senhas, tokens e dados pessoais.
- **Testes por plataforma** — use o modelo de teste para registrar a plataforma,
  a engine, os serviços e o que funcionou ou falhou. Para a campanha de Podman
  em Linux nativo, publique o resultado na issue de validação quando ela estiver
  disponível.
- **Novos serviços** — abra uma issue com o modelo de sugestão. Descreva o caso
  de uso, a imagem, as dependências, as portas e a persistência de dados.
- **Commits** — mantenha cada commit focado e use um título curto e descritivo,
  como `Corrige a inicialização do n8n no Podman`.
- **Pull requests** — use uma branch a partir de `main`, descreva a mudança,
  vincule a issue relacionada e informe onde e como testou. Atualize a
  documentação se houver mudança de uso.

[Escolher um modelo de issue](https://github.com/tulio-tbf/lab/issues/new/choose)
